Resume Master — Capture Shortcut

Press the shortcut on any job posting to capture it into your Resume Master job pool. The default is Ctrl+Shift+K (⌘+Shift+K on Mac).

Shortcuts are set in Chrome's own shortcuts page, which is the only thing that can actually rebind one — an extension cannot reassign its own keys. This page used to record a custom combination itself, but that only worked while one of six job sites had focus, because it was implemented by a script running on those pages. Capture no longer works that way: it runs on whatever page you invoke it on, so the shortcut is Chrome's to own and it works everywhere.
