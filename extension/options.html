Resume Master — Keyboard Shortcuts

Two shortcuts, one for each half of the job. Press the first on a job posting to capture it into your job pool. Press the second on an application form you have already signed in to reach, and the answers you prepared in Resume Master are filled in for you to review. Resume Master never submits an application — you do.

Shortcuts are set in Chrome's own shortcuts page, which is the only thing that can actually rebind one — an extension cannot reassign its own keys. This page used to record a custom combination itself, but that only worked while one of six job sites had focus, because it was implemented by a script running on those pages. Neither shortcut works that way now: each runs on whatever page you invoke it on, so the keys are Chrome's to own and they work everywhere. If one reads “Not set” above, Chrome declined the default — usually because another installed extension already claimed that combination — and assigning any free key there fixes it.
