Résumé tools that show their work.

Check a résumé against a job and see exactly which terms matched, format it, or read the text out of a PDF — free, with no account. Tailoring it uses an account. Nothing you send is kept unless you ask, per document.

ATS check

Scores your résumé against one posting with the same deterministic scorer draft uses — zero model calls, so it is free and unlimited. You get a band and the evidence behind it, never a bare number.

Format

Turns a résumé into a clean, print-ready page with a fixed layout — deterministic, no model. Paste HTML, or plain text with one line per heading, role or bullet.

Tailor a résumé

Rewrites your résumé for one posting. ⛔ It is checked before you see it: a draft that claims more years or seniority than you stated is withheld, not shown. It can still word things you did not — read every line before you send it. One credit, charged only if a résumé comes back.

PDF → text

Reads the text out of a résumé PDF (up to 10 MB) so you can check or tailor it. Free, no account — it reads the text the PDF already carries, with no AI. A scanned PDF has no text to read, and reading scans is not offered.
